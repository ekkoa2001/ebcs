# 分阶段计划与阶段 0 验收

业务实现按 README 第 21 节和第 23.1 节进行。阶段名称只表示顺序。阶段 0 和阶段 1 已完成，阶段 1 验收见 [../phase-1/acceptance.md](../phase-1/acceptance.md)。

| 阶段 | 内容 | 完成边界 |
| --- | --- | --- |
| 0 | 冻结当前 V1 | Git、备份、功能清单、截图、迁移映射、接口和权限设计 |
| 1 | 无视觉变化地整理代码 | 只移动 HTML、CSS、JavaScript，DOM、class、外观和行为不变 |
| 2 | 后端底座 | FastAPI、SQLAlchemy、Alembic、会话、CSRF、RBAC、审计和旧接口兼容层 |
| 3 | 数据和图片迁移 | 新表、图片文件、数量报告、失败回滚；旧页面仍可用 |
| 4 | 品牌创意 | 钩子、出场、脚本、外键、封面、分镜、成品、复盘 |
| 5 | 品牌内容 | 按 README 第 8.1～8.7 节完整实现五个子模块、图片轨道、版本、审核、原图/预览/缩略图和售后生命周期 |
| 6 | 营销方案与生命周期 | 方案、阶段、内容清单和生命周期节点 |
| 7 | 广告数据 | 关联对象、周期数据、服务端指标、罗盘、环比和排行 |
| 8 | 竞品洞察 | 六类洞察、素材、借鉴、复刻和验证 |
| 9 | 首页联动与发布 | 真实汇总、待办、通知、权限、备份恢复、构建和部署说明 |

每个实现阶段结束后都要给出模块、表、迁移、接口、页面、权限、测试、视觉对比、构建、手测步骤、已知问题和下一步。阶段 1 之前不增加模块。
