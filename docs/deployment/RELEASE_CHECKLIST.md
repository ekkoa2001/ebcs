# 正式上线检查清单

## 代码与版本

- [ ] 当前迁移基线已提交 Git
- [ ] 生产发布使用明确版本标签
- [ ] 工作区没有未解释的源码修改
- [ ] 数据库、媒体、日志、密钥未提交 Git

## 后端

- [ ] 所有生产业务接口使用 `/api/v1`
- [ ] 旧兼容接口的保留范围有清单
- [ ] PostgreSQL 迁移可升级、可回滚
- [ ] Redis 中断策略经过测试
- [ ] 权限在后端强制执行
- [ ] 审计日志覆盖核心写操作

## 图片与文件

- [ ] 原图、预览图、缩略图分层保存
- [ ] 对象存储桶默认私有
- [ ] 下载使用短时签名 URL
- [ ] 文件头、MIME、尺寸和大小均校验
- [ ] 已完成本地媒体迁移数量与哈希核对

## 前端与 UI

- [ ] V1 基线页面视觉对比通过
- [ ] 按钮、弹窗、筛选、分页和返回状态通过端到端测试
- [ ] 所有功能包含加载、空、失败和无权限状态
- [ ] 表格与横向图片轨道在常用分辨率下可用

## 安全

- [ ] 生产环境启用 HTTPS 与 Secure Cookie
- [ ] 密码与密钥只通过环境变量或密钥服务提供
- [ ] CSRF、登录限流、失败锁定经过测试
- [ ] 管理员初始化不使用仓库中的默认密码
- [ ] 禁用账号后现有会话立即失效

## 运维

- [ ] 数据库自动备份及恢复演练完成
- [ ] 对象存储版本与生命周期策略确认
- [ ] 健康检查、结构化日志、错误监控和告警已配置
- [ ] 域名、DNS、反向代理和证书已验证
- [ ] 有明确的发布、回滚和应急联系人流程
